# Largest absolute difference between two sparse matrices (C++ kernel)

Largest absolute difference between two sparse matrices (C++ kernel)

## Usage

``` r
cpp_sp_max_abs_diff(A, B)
```

## Arguments

- A, B:

  sparse matrices of the same dimensions.

## Value

\\\max\_{ab}\|A\_{ab}-B\_{ab}\|\\, or `Inf` when the dimensions differ.
