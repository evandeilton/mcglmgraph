Residual graphs with mcglmgraph :: CHEAT SHEET

mcglmgraph adds a graph layer to a multivariate covariance GLM. It fits the mean and dispersion of every response with mcglm(), takes the standardized Pearson residuals and models their between-response covariance Σb as an undirected GGM (on the precision) or a directed DAG (modified Cholesky).

Page 1 · specify, fit,
read and test the layer

Two stages

The mean is not revisited in stage 2. Edges are residual conditional association given the covariates.

Conventions

edgestwo-column integer matrix, one row (i, j) per pair; NULL = complete graph
adjacencya[i,j] = a[j,i] = 1: i — j; only a[i,j] = 1: i → j
GGM par.eta_kk, then one eta_ij per edge
DAG par.gamma_ji (i → j), then delta_j
workersparallel resampling; same seed, same answer at any worker count

A typical session

  1. Fit mcglmgraph() + mc_between_graph()
  2. Read mc_partial_cor(), mc_dag_coefficients()
  3. Test mc_test_independence(), mc_wald_graph()
  4. Select mc_graph_stepwise(), mc_select_lambda(), or discover mc_graph_pipeline(), mc_ges()
  5. Check mc_test_adequacy(), mc_graph_cv(), mc_graph_stability(), mc_graph_bootstrap()

Numerical checks

Before any inference, check in fit$graph: converged, status, score_norm_unit (estimating function left per unit) and rcond_J (conditioning). With inference_ok = FALSE, summary() hides the SEs and the mc_* inference functions refuse the fit.

Specify the layer mcg_graph_spec

mc_between_graph(type = "ggm", edges = NULL, ordering = NULL) Chooses the parametrization of Σb and, optionally, its support.
mc_between_graph("ggm")  # complete
mc_between_graph("ggm", edges = rbind(
  c(1, 2), c(2, 3), c(3, 4)))  # chain
mc_between_graph("dag")  # order 1..R
mc_between_graph("dag",
  ordering = c(2, 1, 3, 4))
mc_between_graph("dag",
  edges = rbind(c(1, 3), c(2, 3)))

ordering is DAG-only: the precision support is unordered, so it is an error with "ggm".

Fit mcglm_graph

mcglmgraph(linear_pred, between_graph, data, matrix_pred = NULL, control = list(), …) One formula per response (R ≥ 2). Arguments in … go to mcglm::mcglm(). mcglm_graph() is the same function under its older name.
forms <- list(y1 ~ x, y2 ~ x,
              y3 ~ x, y4 ~ 1)
fit <- mcglmgraph(forms,
  mc_between_graph("ggm"), data = dat,
  link     = c("identity", "identity",
               "log", "identity"),
  variance = c("constant", "constant",
               "tweedie", "constant"))

Passed to mcglm()

variance"constant", "tweedie" (power 1 ≈ Poisson, 2 gamma), "poisson_tweedie", "binomialP"/"binomialPQ" + Ntrial
link"identity", "log", "logit", … one per response
power_fixedfix or estimate the power parameter
matrix_predwithin-response structure; default mc_id(), independent rows

control =

max_iter, tol, score_tol, rcond_tol, verbose; dag_solver = "closed" (exact, default) or "newton" (same root).

Read the fit

print(fit) · summary(fit) Layer, R, n, edges, convergence and Σb; the summary adds the mcglm tables, graph parameters, partial correlations and AIC/BIC/QIC.
coef(fit, type = "graph") Also "regression" or "dispersion"; no type returns the inherited mcglm table.

Inside fit$graph

Sigma_b, K_bfitted covariance and precision
par, vcovgraph parameters, model-based Jn−1
Shat, residualsŜe and the n × R Pearson residuals

Inherited mcglm methods (vcov, gof, pAIC, pBIC, anova, confint, fitted) describe stage 1. The graph layer is read through the mc_* helpers.

Read the graph layer

mc_partial_cor(fit) ρij·rest = −Kij / (KiiKjj)1/2, the reading of either layer.
mc_partial_cor_delta(fit, variability = "model") Delta-method SE, Wald z, p-value and CI per pair; also "empirical", "two_stage". present = structurally allowed (GGM support, moral graph of a DAG).
mc_dag_coefficients(fit_dag, interval = "delta") Scale-free quantities of the DAG, the ones to report: γ*jk = γjk(Σkk/Σjj)1/2 and R2j·Pj = 1 − δj/Σjj, with SE and intervals.
mc_get_graph(fit, threshold = 1e-4) $adjacency and $edges; directed along the ordering for a DAG.
mc_plot_network(fit, threshold = 0.05, edge_labels = FALSE) Circular layout; width = magnitude, color = sign. plot(fit, type = "residuals") draws residual histograms.
fit_dag <- mcglmgraph(forms,
  mc_between_graph("dag"), data = dat,
  link = …, variance = …)
round(mc_partial_cor(fit), 2)
mc_dag_coefficients(fit_dag)$nodes

Inference on the layer

mc_vcov_graph(fit, type, cluster, small_sample, method, sensitivity) Covariance of the graph parameters, in three forms:
typeformassumes
"model"Jn−1V = J: Gaussian fourth moments
"sandwich"H−1(nV̂)H−1centered scores per unit or cluster
"two_stage"sandwich + stage 1adds the first-stage uncertainty

The first two are conditional on the residuals. For "two_stage", method = "shortcut" needs one multiplicative dispersion per response, identity matrix_pred, constant weights; "full": any family, sensitivity = "observed" or "expected". "auto": shortcut if it applies and no DAG immorality.

mc_two_stage_available(fit, cluster) Which route applies, and why not.
V <- mc_vcov_graph(fit, "two_stage")
sqrt(diag(V))[attr(V, "edge_pos")] # SE

Under conditions (a)–(c) of ?mc_vcov_graph, which the shortcut relies on, the correction vanishes to first order on partial correlations and zero-precision entries; the diagonal and Σb need it.

Tests

mc_wald_graph(fit, L, rhs = 0, type = "sandwich") H0: Lθ = c; L as a contrast matrix, a vector, or parameter names.
mc_wald_graph(fit, c("eta_13", "eta_14"))
mc_test_independence(fit, robust = FALSE, type) All edge parameters zero: no residual conditional association. Model-based by default; type = "sandwich" or "two_stage".
mc_test_adequacy(sel$fit) Omitted edges jointly zero, against the saturated graph refitted on the same residuals.
mc_edge_scores(fit, which = "both", variability = "model") χ21 per pair without refitting: Wald for present edges, efficient score for absent ones (GGM).

The three Wald tests take cluster and small_sample (G/(G−1)) and return an htest.

Compare supports

mc_compute_criterion(fit, which, ebic_gamma = 0.5, cluster) Working criteria of the residual layer:
"aic", "bic"parameter count, penalty 2 or log n
"qic", "gbic"effective dimension tr(H−1V), penalty 2 or log n
"ebic"BIC + 4γ|E| log R (Foygel & Drton)

"clbic" is a legacy alias of "gbic". The attribute criterion_status says whether the effective dimension came from a well-conditioned sensitivity.

mc_graph_ploglik(fit) ℓ = −½n[R log 2π + log|Σb| + tr(Σb−1Ŝe)], the scalar all criteria build on.
mc_graph_cv(fit, supports, folds = 5) Held-out working criterion per unit (larger is better), first stage held fixed; no penalty, no reuse of the selecting sample.
mc_compute_criterion(fit,
  c("bic", "gbic", "ebic"))
mc_graph_cv(fit, supports = list(
  full = NULL, selected = sel$edges))

Select a GGM mcg_selection

mc_graph_stepwise(fit, direction = "backward", criterion = "bic", k_confirm = 3) Greedy search from the complete (backward) or empty (forward) graph; edge scores rank candidates, the top k_confirm are refitted per step. GGM fits only.
mc_select_lambda(fit, n_lambda = 30, criterion = "bic", warm_start = FALSE) L1 path from the penalty that empties the graph; selects λ, refits the support, keeps $lambda_path.
mc_graph_penalized(fit, lambda) Proximal gradient with a KKT certificate ($converged, $kkt_unit). λ is on the accumulated scale: take it from mc_select_lambda().
sel <- mc_graph_stepwise(fit)   # BIC
sel$edges; plot(sel)
mc_test_adequacy(sel$fit)
lam <- mc_select_lambda(fit,
  criterion = "ebic", warm_start = TRUE)
# fix a support and refit
mcglmgraph(forms, mc_between_graph("ggm",
  edges = sel$edges), data = dat, …)

Discover a CPDAG mcg_cpdag

mc_graph_pipeline(fit, alpha = 0.05, orient_method = "pc", orient_rule, required, forbidden, max_ord, df_residual) PC-stable skeleton on the residual partial correlations (Fisher z), colliders, then Meek's rules. Returns $cpdag, $vstructures, $valid_cpdag, $label and $gates.
orient_rule"standard": the one recorded separating set; "conservative", "majority": all of them, order-independent
orient_method"pc" native; "hc", "tabu" via bnlearn
required, forbiddenbackground arcs (from, to); output is then a maximally oriented PDAG
df_residual"auto": νe − |S| − 2 if mc_residual_df(fit) is exact, else refused

Labeled a CPDAG only when all 7 gates pass, e.g. no collider conflict, no directed cycle, colliders survive Meek, a DAG extension exists.

mc_ges(fit, penalty = NULL, start, max_set = 12) Greedy equivalence search (Chickering), score-based and native; default log(n), 2 gives AIC. Disagreement with PC is informative.
cp <- mc_graph_pipeline(fit,
        orient_rule = "majority")
cp$cpdag; cp$valid_cpdag
mc_graph_pipeline(fit,
  required = rbind(c("y1", "y2")))
mc_ges(fit)

Check against a known truth

mc_structure_metrics(est, truth, R) Undirected recovery: tpr, fpr, precision, f1, shd and counts.
mc_true_cpdag(T) CPDAG of a known DAG (Tji ≠ 0 ⇔ i → j).
mc_cpdag_metrics(est, truth) CPDAG SHD, skeleton F1, v-structure recall and precision, orientation recall, over-orientation.
mc_sid(truth, est) Structural intervention distance: wrong adjustment sets. An interval [lower, upper] for a CPDAG.

Building blocks

mc_pc_skeleton(Sigma, n, alpha, max_ord, df_residual) Skeleton and the first separating set of each pair.
mc_separating_sets(Sigma, n, adjacency) Every separating set on the final skeleton, with its partial correlation and p-value.
mc_find_vstructures(fit, orient_rule) Unshielded triples: collider, applied, ambiguous.
mc_orient_meek(amat, ambiguous, required, forbidden) Rules R1–R4 until nothing else can be oriented.
mc_residual_df(fit) νe = n − h: constant variance, identity link, unit weights, one design space; else why not.

Equivalence classes

mc_class_members(cp, max_members = 1000) The DAGs a CPDAG stands for; attribute truncated.
mc_class_coefficients(fit, cp) Range of each arc's coefficient over the members. common flags arcs the class pins down: no undirected edge touches their head. Report one number only for those.
mc_dag_closed_root(Shat, R, edges, directed) With directed = TRUE fits any acyclic set of (parent, child) arcs as node-wise least squares, γj = SPjPj−1SPjj; ordering derived by Kahn's algorithm.
mc_class_coefficients(fit, cp)$arcs

  directed = TRUE)

Read with care
  • A missing GGM edge means no second-order conditional association; it is conditional independence only under joint normality of the residuals.
  • The DAG is an ordered residual parametrization. A causal reading needs a defensible ordering, causal sufficiency and faithfulness.
  • After a search over graphs, p-values and intervals are descriptive.
  • "model" and "sandwich" are conditional on the residuals; use "two_stage" or the bootstrap to carry stage 1.
  • Rows or clusters must be independent units: covariates in the mean do not whiten spatial residuals.
